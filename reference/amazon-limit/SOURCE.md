# Amazon boundary source

- File: `raisg_biomes_2025.zip` (shapefile `Biomas_2025/Biomas.shp`, CRS SIRGAS 2000 geographic, UTF-8 attributes)
- Downloaded 2026-10-28 from https://www.raisg.org/en/download/biomes/ (listed on https://www.amazoniasocioambiental.org/en/maps/)
- Features: 8 biomes. The Amazon is `id_bioma = 1` (`bioma = "Amazonía"`); the others (Andes, Cerrado, Chaco, Pantanal, Tucumano-Boliviano, Chiquitano, Valles) must be dropped.
